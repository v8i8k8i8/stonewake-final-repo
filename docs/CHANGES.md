**Note on C-15 (19:00):** C-15 was made under the QA Lead's rule "if the sidebar link is not a documented requirement".
At ~19:00 the public product docs were checked for the first time: `https://docs.stonewake.ai/dossiers`, section
"Where to find it", states that **EDD Dossiers in the sidebar** opens the workbench for every team whose workspace
holds the dossiers module. The rule's premise therefore does not hold, unless this workspace lacks the module
(the page and its "New dossier" button do work). At 19:12 the workspace settings confirmed the module is enabled,
so the issue was filed as product defect IN:86 (19:29) and the sidebar check came back as its own skipped test (C-17).
See [ED-06](ENGINEERING_DECISIONS.md#ed-06--ui-6--edd-dossiers-sidebar-link-and-new-ui-11) and
[DEFECTS.md DEF-P-01](DEFECTS.md#def-p-01--sidebar-does-not-show-edd-dossiers-although-the-dossiers-module-is-enabled).
